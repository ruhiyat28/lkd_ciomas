Panduan Urutan Penghapusan

Karena data saling terhubung, hapus dalam urutan ini agar tidak terjadi error:

  1. Pembayaran — tidak bergantung ke modul lain
  2. Jurnal Akuntansi — dapat dihapus kapan saja
  3. Pinjaman — hapus setelah pembayaran bersih
  4. Nasabah — hapus setelah pinjaman bersih
  5. Aset — independen, dapat dihapus kapan saja
Sebelum Menghapus
  • Export data penting ke Excel terlebih dahulu
  • Backup file database (lkd.db) secara manual
  • Pastikan tidak ada user lain yang sedang mengakses sistem
  • Tindakan ini tidak dapat dibatalkan (no undo)
